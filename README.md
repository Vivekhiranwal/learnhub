# LearnHub - Online Learning Platform

LearnHub is a modern online learning platform that provides high-quality courses and educational resources. The platform features a responsive design, user-friendly interface, and comprehensive learning management system.

## Features

- Modern and responsive design
- User authentication (login/register)
- Course catalog and enrollment
- Interactive learning dashboard
- Help center and support
- Blog and resources
- Newsletter subscription
- Social media integration

## Pages

- Home (`index.html`)
- Courses (`courses.html`)
- About (`about.html`)
- Contact (`contact.html`)
- Login (`login.html`)
- Register (`register.html`)
- Blog (`blog.html`)
- FAQ (`faq.html`)
- Help Center (`help.html`)
- Privacy Policy (`privacy.html`)
- Terms of Service (`terms.html`)
- Security (`security.html`)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/learnhub.git
```

2. Open the project in your preferred code editor

3. Open `index.html` in your web browser to view the website
